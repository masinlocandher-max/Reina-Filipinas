# Reina Filipinas

A polished, responsive website for Reina Filipinas and its 2026 inaugural titleholders. The interface combines champagne-gold pageant glamour with emerald depth and iOS-inspired glass surfaces.

## Routes

- `/` — Minimal video hero, caption and primary buttons
- `/about` — What Reina Filipinas is and who leads it
- `/the-pageant` — Editorial story covering the inaugural winners, hosts, judges and royal court
- `/mgi-all-stars` — Alexie Brooks and Anne Patricia Diaz
- `/miss-grand-philippines` — Angelica Lopez and the national franchise pathway
- `/contact` — Official social channels and local inquiry composer

## Run locally

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run lint
npm run build
```

## Design system

- Display: Cormorant Garamond
- Interface: Manrope
- Palette: true black, deep emerald, champagne gold and ivory
- Responsive targets: desktop, tablet and iPhone-sized mobile viewports
- Figma handoff: [Reina Filipinas — Official Website 2026](https://www.figma.com/design/BAdItfEXIEu4uzMxyYhpDI)

## Content notes

The candidate directory filters locally by name, locality or result. The contact form prepares an inquiry entirely in the visitor’s browser. Neither interaction uploads or stores personal data.

Editorial source links are included in the website. All page copy is original and the supplied Reina Filipinas portraits are stored in `public/images`.
